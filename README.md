# 🚀  My Kernel Builder 

### Default Workflow Settings

| Setting | Description | Default |
|---------|-------------|---------|
| **Kernel source URL** | Your kernel repository URL | `https://github.com/NotPichayut/This-is-my-Kernel-Builder` |
| **Kernel branch** | Branch to build from | `zepharo` |
| **Device** | Device name for defconfig | `gki` |
| **Custom localversion** | Add custom version suffix | (empty) |
| **Build KSU variant** | Include KernelSU version | `true` |
| **KSU variant** | KernelSU Manager | `SukiSU` |
| **Kernel Optmization** | Optimization Level | `03` |
| **LTO mode** | Optimization level | `full` |
| **Tickrate** | Custom Tickrate Options | `300hz` |
| **BBG** | Add BBG Support | `off` |
| **Swap for runners** | To prevent workflows from failed cause running out of space | `8GB` |
